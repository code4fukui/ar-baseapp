# ar-baseapp


Three.jsとWebXRを使用してAR（拡張現実）体験を作成するためのベースアプリケーションです。

## デモ
`geometry.html`ファイルは、`initAR.js`の`initAR()`関数を使用して赤いキューブのあるARシーンを作成する簡単な例を提供します。

## 特徴
- WebXRをサポートするThree.jsシーンをセットアップするためのボイラープレートを提供します
- 必要なシーン、カメラ、レンダラー、コントロールをセットアップする`initAR()`関数が含まれています
- 3DオブジェクトとAR機能の簡単な統合を可能にします

## 要件
- WebXRをサポートするモダンなウェブブラウザ（例: Chrome、Firefox、Edge）
- AR機能を持つデバイス（例: スマートフォン、タブレット）

## 使用方法
`ar-baseapp`プロジェクトを使用するには：

1. リポジトリをクローンするか、ファイルをダウンロードします。
2. 互換性のあるウェブブラウザで`geometry.html`ファイルを開きます。
3. デバイスのカメラとAR機能にアクセスするために必要な権限を付与します。
4. デバイスを動かしてARシーンとインタラクトします。
